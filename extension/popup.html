    Connect an agent

    Video path: live Amazon + DevTools/Inspector executeTool (see repo docs/VIDEO_AMAZON.md). WebMCP tools live on the page, not as a separate MCP server. The agent must open this tab’s URL in a WebMCP-capable browser.

    1. ChatGPT / Codex (real agent) — Desktop app → built-in browser → open this page (demo: http://localhost:8765 or a public HTTPS URL). Use model GPT-5.6 Sol or Terra (not Luna). Click Site tools in the address bar; ask e.g. “list site tools, then search for kettle and add Electric Kettle to cart.” Extension does not run inside ChatGPT’s browser — use the demo’s built-in auto-WebMCP (or host that page).
    2. Chrome (manual / Inspector) — Enable chrome://flags/#enable-webmcp-testing, reload this page with Site2WebMCP on, install “WebMCP - Model Context Tool Inspector”, or paste the debug snippet in DevTools.
    3. Other agents — Only clients that speak page WebMCP (in-page document.modelContext) work. Classic MCP stdio/SSE connectors will not see these tools.

    Flag: chrome://flags/#enable-webmcp-testing

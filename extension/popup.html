    Connect an agent

    WebMCP tools live on the page, not as a separate MCP server. Prefer Codex + agent-browser (Chrome with this extension). ChatGPT’s built-in browser does not load extensions.

    1. Codex — Use agent-browser / Chrome with Site2WebMCP loaded; open the site; ask it to list WebMCP tools and run a short workflow.
    2. Chrome debug — Enable chrome://flags/#enable-webmcp-testing, reload the page, use DevTools getTools() / Tool Inspector, or copy the debug snippet.
    3. Other agents — Only clients that speak in-page document.modelContext. Classic MCP stdio/SSE connectors will not see these tools.
